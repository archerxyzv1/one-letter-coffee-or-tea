An entry for make.fun's bounty **"One Letter: Coffee or Tea"** ($5). The entry is exactly one letter and nothing else: A for coffee, B for tea, with no word, no explanation and no punctuation.

## The letter

> **A**

A is **coffee**: the fuel of a builder up late working through the night, vivid, funny and true. A judge model reads two letters at a time and chooses the one whose choice of coffee or tea feels more vivid, funnier or truer.

## What this repository holds

- `main.ts` — the program. It writes the letter to `/output/entry.txt`, where the gate reads it, and refuses anything that is not exactly one letter A or B. Node 22, standard library only, no network.
- `LICENSE` — MIT.
- `.makefun/owner.json` — the payout wallet.

## Run it locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`out/entry.txt` is then the single letter, byte for byte.
